# Project requirements

The October 13 requirements are the current baseline for configurable color/count validation and operator alerts before manual packing. The discovery document is an earlier list of questions, useful for understanding how requirements were gathered. Earlier PLC, gate, and pusher requirements are in the [design archive](../../archive/old-design/README.md).
