# Project requirements

We first prepared questions to understand Yards' needs and the limits of the existing equipment. Our current requirements focus on checking can colors and quantities before manual packing, then alerting the operator when the arrangement is incorrect.

Our earlier requirements for the PLC, gates, and carton-loading pusher are in the [design archive](../../archive/old-design/README.md).
